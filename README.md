## 코드 통합
- 쿠버네티스 매니페스트
- mlflow MLproject
- 환경변수: 비민감 값 ConfigMap / 민감정보 Secret 분리

## 아쉬운 점
- Makefile 미완성 (모델 등록이 자동화 안 됨)
- 평가 로깅은 MLflow에 남지만, frontend 질문 내역은 미연동
- Remote MLflow 미구현 (로컬 클러스터 내부에서만 서빙)
- 평가용 가상환경(pyenv)이 파드 재시작 시 소실됨
- 평가가 backend API를 거치지 않는 모델 단위 테스트 (통합 테스트 아님)
